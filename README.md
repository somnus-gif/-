# 智游策划师 (zhiyou-planner)

面向旅游从业人员的全流程策划工具微信小程序。

## 功能模块

- **客户管理**: 客户档案、阶段跟进、沟通记录
- **景点库**: 景点信息管理
- **行程规划**: 多日行程编辑与预览
- **报价管理**: 报价单生成与版本追溯
- **订单管理**: 合同、收款、预订状态跟踪
- **机票查询**: 航班查询与选择
- **酒店方案**: 酒店方案对比
- **个人中心**: 用户信息与设置

## 技术栈

- 微信小程序原生开发
- 微信云开发 (Cloud Functions)
- 云数据库

## 项目结构

```
├── pages/           # 页面文件
├── cloudfunctions/  # 云函数
├── utils/           # 工具函数
├── app.js           # 入口文件
├── app.json         # 全局配置
├── app.wxss         # 全局样式
└── project.config.json  # 项目配置
```
